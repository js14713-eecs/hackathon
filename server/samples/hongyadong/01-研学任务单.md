# 洪崖洞是怎么“长”出来的？

——重庆山城建筑小队研学任务单

时间：2026年7月13日—7月17日
队员：六名五年级学生（小雨、阿泽、乐乐、思思、豆豆、圆圆）
带队：周老师
地点：重庆市渝中区洪崖洞、千厮门大桥、重庆中国三峡博物馆

核心研究问题：洪崖洞的吊脚楼为什么能建在这么陡的悬崖上？

出发前我们想问：
- 吊脚楼的木柱子插在崖壁上，房子为什么不会倒？
- 洪崖洞明明有十一层，为什么每一层走出去都像是一楼？
- 以前住在江边的人，为什么要把房子修成这个样子？

## 行前准备
- 在教室里用纸板搭吊脚楼模型，第一次搭到第三层就塌了，第二次给柱子加了斜撑才立住。
- 查地图发现洪崖洞紧挨着嘉陵江，江面比房子最低的一层还要低。
- 每人准备一本观察本，约定每天回酒店后画一张速写、写三条发现。
- 周老师提醒我们：不要只看网红打卡点，要蹲下来看柱子是怎么落地的。
